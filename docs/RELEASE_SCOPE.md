## 與完整產品規格的差距

- 3D 幾何只支援明列的實作類型：階梯、半磚、門、床、木原木及部分立方體。其他特殊方塊顯示不支援標記；未完成完整活板門、玻璃片、柵欄／牆連接、植物等形狀。示意色不等於原版材質貼圖。
- 未見完整自由筆刷、拖曳連續繪製、互動框選工具、可重用窗／門／陽台元件庫及貼上預覽。現有整數範圍批次工具提供部分替代流程，不代表這些完整規格項目已完成。
- 藍圖目前點選／鍵盤一次操作一格；未見藍圖原生拖曳繪製、區域選取／貼上等完整工具組。大量操作透過共用批次面板。
- 未見原圖／生成結果比較、完整照片分析證據標註、完整快照差異比較介面；照片真實尺寸與隱藏內部無法保證。
- 尚未實作原生 Java Structure NBT 或 Litematica 匯入／匯出；JSON／CSV 不是這些格式。原生格式屬規格列明的後續選項，不能假稱已支援。
- 沒有完整 Minecraft 世界物理／鄰接更新／重力穩定性／生存取得／可達性模擬，沒有遊戲內驗收。施工提示不能保證每個設計在生存模式可直接建成。
- 透明實例未逐個深度排序；大型設計的流暢程度必須以量測為準。雲端同步與多人協作屬首版範圍外。
