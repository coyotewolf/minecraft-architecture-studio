## Implemented release journey

The public UI creates an empty project, imports the canonical house model, places a roof cell through real 3D picking, edits the corresponding 2D layer, verifies material demand/prepared quantities, saves and reloads through native IndexedDB, approves and marks construction progress, exports workspace and XYZ CSV, and reimports the backup. Downloaded data is independently decoded and compared for design, original/approved snapshots, completion, preparation, view and revision history. Shared engine tests and batch browser cases verify atomic undo, legal states and paired structures.

The second release scenario launches the compiled Node server on loopback port 5291, checks its page and real capabilities endpoint, opens it in Chrome, verifies clear AI disablement with blank provider settings, and exercises manual placement/undo. This is the same built server shipped by npm start, not a static preview substituting for API behavior. No external paid request is sent.

## Integration audit and repaired defect

Astra medium performed independent source review and reproduced a data-loss race with a delayed native IndexedDB open: confirming an edit while a header switch saved the older model could lose the new cell. The final implementation serializes header switches, disables duplicate header actions, retries saving whenever any workspace field changes during the write, and abandons a stale transition when another engine/workspace is opened. Editing remains available while saving. Three added browser regressions cover mid-save editing, same-event duplicate dispatch and same-ID import during a pending switch. All nine persistence cases passed after repair; the complete suite below tests the integrated fix.

Earlier independent reviews repaired invalid proposal/image/body limits and the original-AI marker's dependence on prunable history. The first accepted AI design now survives log pruning/import and subsequent accepted proposals. No engine, renderer or IndexedDB mock replaces the production paths in release tests; configured AI responses alone are explicit test fixtures.
