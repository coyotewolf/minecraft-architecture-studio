## 檢視、編輯與匯出

全基地總覽共用原始世界 XYZ。對不透明、完全遮蔽的內部面進行顯示剔除，只減少繪圖面，不刪除 canonical 方塊、不修改座標，也不改變材料或匯出內容。

每個分區可獨立開啟進入原有編輯工作台，均低於 **50,000 格**；核心單一 Project 限制未放寬。188,212 格是多分區總覽與集合，不是假造一個超出核心容量的單一可編輯專案。

- 全基地 JSON 使用 **minecraft-campus-1** 集合 schema，包含分區 metadata 與各自有效的 Project、全域座標及來源。它不是一般單一 Project JSON，不能宣稱可直接由單專案匯入器讀入。
- 全基地 CSV 從全部 canonical records 輸出分區、UID、ID、XYZ、分類、狀態及推估標記；材料清單亦涵蓋全部分區。
- 分區進入工作台後仍可使用原有模型／工作區備份流程。全基地集合不是 NBT 或 Litematica。
