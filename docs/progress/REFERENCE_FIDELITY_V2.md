## 改動內容

- 中央指揮塔改為窄基座、凸透鏡主體與尖冠；兩個立面都有深色交叉支架，外側改用更寬的白色肋與金邊。
- 環門塔改為左高右低、沿大部分高度逐層收窄的深色刀鋒，保留大型白環與金色縱肋。可使用樓層與樓梯留在塔身內。
- 雙住宅／圖書塔改為不等高蛋形塔、薄白樓環及透明連橋；天文館移除大片玻璃腰帶，改為近乎全白球體與少量窄窗。
- 工業區、懸架空港、六連龍舍及斜撐工坊重新建模；空港強調高架立方量體、下方飛船泊位及高空廊橋。
- 農牧溫室降低為寬闊淺藍玻璃筒拱；住宅改為三組不等高退台量體與密集綠色露台；粉色亭降低為半球，周圍加入白色廣場與金色放射線；金字塔改為金色屋頂架在白柱玻璃基座上。
- 調整建築相對位置與高程，新增不規則岩島、層疊山脊、密林、露台植栽、白色曲線步道、橋網、逐格玻璃瀑布及景觀環門。
- 配合整體圖調整相機構圖與光照。遠景中的建築、岩壁與樹木來自實際 canonical 方塊，沒有用假背景建築冒充已建模內容；海面是展示用平面，不計入方塊與材料。
