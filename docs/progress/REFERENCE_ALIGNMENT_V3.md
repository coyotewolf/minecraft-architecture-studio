# 參考構圖與細節 V3

狀態：目前預設模型，幾何已凍結。完整靜態檢查與建置通過；三項基地瀏覽器案例已分次取得通過，執行與修正紀錄見下方。

## 為何重作

使用者拒絕 V2 的視覺相似度，要求更細的 Minecraft 建築尺度，並以原圖相同視角檢查。V3 重新建立實際樓層、窗框、肋架、陽台、室內與階梯，不是把 V2 方塊整體放大。V2 報告保留為歷史，不代表使用者已接受其外形。

## 固定構圖與比較

src/fixtures/campus/reference-layout.ts 集中保存正交相機及十二組建築原點。參考畫框為 1536 × 1024（3:2），yaw 35°、pitch 32°；各組原點由參考圖的估計地標與選定高程推導，再以實際 canonical 座標呈現。這是座標中心的投影對齊，不代表輪廓、比例、遮擋、材質或每個像素相同。工廠、空港及其他建築的原點仍是人工推估。

介面支援左右並排與透明疊圖，可調參考圖透明度、顯示地標並回到參考圖視角。比較的模型是真正可編輯方塊；沒有用背景圖片冒充建築。海面為展示平面，不列入材料。

## 凍結資料規模

由 [reference-v3-summary.json](../../evidence/reference-v3-summary.json) 核對：**1,491,644 個佔用格、1,491,583 件物品、59 種材料**，共 **39 個工作區分片（17 建築＋22 地形）**。十二組建築合計 **506,107 格**，地形 **985,537 格**；物品數與佔用格數分開統計。

同一組大型建築可拆成多個工作區。分片以 45,000 格為目標上限，門／床成對成員原子保留，不將一對拆散；每片仍低於核心 50k 限制。全基地 JSON 是 minecraft-campus-1 多專案集合，不是突破單一 Project 上限。來源維持 AI Estimated Area，包含推估的隱藏室內與尺寸。

完整基地包圍範圍為 X857 × Y193 × Z815 格。以下弧面、直徑及高度為造型設計參數；實際佔用格數須用座標 max−min＋1，包含外伸走廊。指揮塔整組為 X71 × Y156 × Z51，環塔整組為 X131 × Y116 × Z36；逐組精確界限見 [reference-v3-bounds.json](../../evidence/reference-v3-bounds.json)。

## 驗證狀態與界線

完整型別檢查、lint、**1,348 項測試／34 檔案**及正式建置通過。花園與工業的幾何測試保留合法解析、精確邊界、無重複座標、分片門床完整性、窗肋與飛船細節、樓梯淨空及平台銜接等斷言。三項基地瀏覽器案例均取得通過結果，但不是一次乾淨的三案執行：初次 **2 通過／1 失敗（280.507 秒）**，完整匯出／精確選取與手機觸控通過；施工案例先修正雙層地基的測試選點假設，再修正施工相機 −Z／+Z 方向。中途一次初始渲染等待停滯已中止並保留追蹤，未增加等待門檻；全新環境重跑施工案例 **1／1 通過（206.995 秒）**，核對放置、完成標記、返回重開及下載內容。另一次相機假設失敗（125.147 秒）亦保留。

瀏覽器使用 Chrome 155.0.8059.79／SwiftShader、Vite 開發伺服器及隔離儲存空間；Node 測試程序使用 8GB heap 解析大型下載，瀏覽器設定未降低。正式前後端建置另行通過，資產為 index-DIIwI45X.js；未重跑全部歷史案例。完整紀錄與證據檔案見 [reference-v3-browser-summary.json](../../evidence/reference-v3-browser-summary.json)。
