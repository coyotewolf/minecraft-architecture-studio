# 收藏逐棟載入與安全首頁（2026-10-22）

使用者回報 page crash。未取得該分頁的瀏覽器崩潰 dump，不能確認唯一觸發原因；但確認兩個高記憶體路徑：收藏啟動時 getAll 全部壓縮建築並同時保留解壓模型、再載入全部施工紀錄；裸根網址則同步生成整座大型基地。上一輪放寬格數上限沒有改善這些記憶體行為。

## 實作

- 收藏 React state 改為輕量 Library 索引與單一選取 Project；選取才讀取一筆壓縮建築及它的施工紀錄。快速切換會序列化讀取並忽略過時結果，釋放舊預覽與模型。
- 新內部 storageVersion4 索引記錄每棟來源、名稱、筆記及已知格數／版本；既有 version2/3、舊 inline 備份仍相容。舊 inline 資料首次保存會在同一交易留存原件，不刪除原儲存。
- 保存只壓縮明確提供的新／變更建築，其他紀錄不讀取、不 clear。收藏與建築庫名稱筆記及選取可持續保存；完整 JSON 下載仍是一棟一檔。
- 全收藏備份逐棟讀取並組成 Blob，不在 React 保留全收藏解壓陣列；完整備份仍受512MiB限制，屬明確使用者操作。
- 施工專案清單用 cursor 讀取標題與時間；新壓縮 envelope 附帶清單資訊，舊壓縮紀錄以識別碼顯示，點選才解壓。施工頁的手動清單也採相同方式。
- / 顯示不建立模型的選擇頁；完整基地由明確按鈕或 view=campus 開啟，延遲載入 CampusPanel。離開基地清除模組快取；離開施工清除父元件保留的初始模型。
- 首次保存失敗仍保留唯一未保存模型以供預覽／下載；追加失敗保留舊清單。
- 金葉塔幾何沒有更改。未清除使用者收藏，沒有付費生成。
