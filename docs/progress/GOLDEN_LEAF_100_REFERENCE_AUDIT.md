# 金葉塔 100 格上限：原圖重讀與尺寸取捨

日期：2026-10-21。狀態：參考分析完成；以下為實作建議，不是已完成的 100 格模型或驗收結果。本次僅寫本報告，未修改模型、未呼叫 Higgsfield、未使用付費生成。

## 依據與約束

已重新直接觀看使用者原始 `葉子前視圖.png`、`葉子後視圖.png` 與現有 `evidence/golden-leaf-comparison.png`。兩張原圖本身已是 Minecraft 方塊建築風格，應還原其構造層次，不能以「方塊化」解釋原先扁平的窗面與葉片差異。

已閱讀 AGENTS.md 與產品／架構／驗收相關文件。沿用 canonical 方塊模型、整數座標、真實半磚狀態、成對門及未知內部推估標記；本報告不變更核心介面。使用者的新上限優先於先前 214 格版本：**包含最低基座、階梯、植栽與最高尖端，maxY − minY + 1 必須 ≤100。** 建議明定最低 Y0、最高 Y99，而非把塔身 100 格另加基座。

圖中光暈、亮度不能證明原作者使用了哪個光源方塊；以下指定螢石是可施工替代方案。圖片的尺寸、深度、房間、側面與材料 ID 均不能視為已測得實值。14° 俯角是由屋頂橢圓推估的比較視角，不是精確相機校準。

## 圖形分解與必須保留的關係

### 正面

整體是上尖下收、下半段飽滿的雙葉包覆塔。前圖左葉較低、右葉較高；左葉尖是獨立圓尖，兩尖之間有明確凹口，不是一道水平肩部。金色葉面為厚實凸曲面，白色內緣沿整個窗洞轉彎並包回側壁。最大寬度落在中下段，底端再內收接裙樓，不能做成長段直立側牆。

正面深藍窗占較寬中央區，兩條主要灰白直肋向下形成大 X／收腰形；它們是窗前構件，不是玻璃上的白線。薄水平樓板向前伸出，側端有暖色亮點；樓板後面才是窗。上段逐層縮小，下段肋架在約塔高 15% 處交會、約 35–40% 處開始斜向收束，比例為目測。原圖約 24–26 道可辨識樓層帶，頂部遮擋與透視使數量有誤差。

### 背面

背面不是正面翻轉貼圖：金葉占大多數，中央只有狹長葉形開口、中央單直肋與少量可見樓板。原圖最寬背窗約為當地塔身寬的 35–40%；下尖約落在塔身底以上 25–30%。原圖背窗可辨識約 12–14 道較明顯水平層帶，比正面少；兩圖並非可逐層一一匹配的工程立面，必須選定同一份樓層資料再由金殼遮住其餘部分。

背面下半部有一片金葉斜覆另一片，斜線從左下往中央窗尖上升，白唇細而連續。應由兩片殼的先後深度形成接縫，而不是在同一平面畫白線；接縫不能到中途變水平腰帶。以世界座標保留同一高低葉，轉到背面時左右自然交換，不可各自調整成兩個不相容模型。

### 基座、入口與附樓

基座是一個有厚白外緣的圓盤、中央曲面裙樓、兩側圓亭。正面階梯正對中門，入口左右有暖色豎向光帶；附樓由白柱、窄藍窗和厚白簷口組成，屋頂高於主裙樓。原圖背面亦可見入口／階梯，但位置有視角偏移，不足以證明完整對稱；可採前後各一入口，註明為設計推估。

原圖地面花壇、屋頂環形花壇、叢狀灌木與少量小樹相互交錯，並非一條平坦草環。白色矮牆框住種植區，暖燈沿行走節點點狀分布；正面入口中軸保持暢通。

## 建議 100 格格網

以下是供實作者調整的起始設計，不是由照片精確量得。全組寬建議 69–73 格，塔最大寬 49–51 格，以 88 格塔高／50 格寬≈1.76 接近參考；避免沿用舊模型 2.0 的修長比再機械減半。

| 部件 | 建議範圍／尺寸 | 實作理由 |
| --- | --- | --- |
| 地面圓盤 | Y0–2，半徑約35 | 厚白底邊保留，階梯不得伸到Y−1 |
| 主裙樓 | Y3–8，屋簷Y9–10 | 入口需2格淨寬、2格高以上；正面階梯3–4階 |
| 兩側圓亭 | 半徑7–8，柱體Y3–10，簷口Y11–12 | 白柱至少1格，簷口厚1格加真半磚層次 |
| 屋頂花園 | 小樹最高約Y15–16 | 可高於亭簷，但不遮主塔下緣交叉肋 |
| 塔體 | 從Y12接起，最高Y99 | 全組100格封頂 |
| 低葉尖 | Y89–91 | 高低差8–10格，保留凹口與獨立葉尖 |
| 背窗下尖 | 約Y35–39 | 保留大片下部金殼，避免窗尖過低 |
| 正面X交會 | 約Y25–28 | 留出下方肋架展開至塔基的空間 |
| 正面斜肋起段 | 約Y44–48 | X不能變成靠底部的小裝飾 |

半徑曲線須平滑跨過中下段最寬處；每一層單格台階可接受，但不能由幾段長直線形成硬肩。殼面厚度1–2格，局部重疊額外外移1格；白葉緣正面寬2格、向內返深2–3格。縮尺後不能把所有構件都捨入成同一個深度。

## 26 層與 100 格的取捨

100 格總高扣除基座及尖頂後，不能保留舊版每層7格及26層。不得把僅有外牆條帶的樓層稱為26個完整寬敞房間。

- **保留層帶數方案：** 26道樓板以3格節距配置，例如Y13、16……88；其上保留約11格漸尖段。使用半磚使窗帶有約2.5格可見高度。這是緊湊層高，上方樓板面積漸小，部分僅為結構／維修平台；樓梯、家具與連續通行仍須另外驗證。
- **較重視內部使用方案：** 約20–22層、4格節距，末段依屋頂截短。較容易安排3格左右淨高與動線，但水平層帶數明確少於原圖。

優先建議第一方案保持26道外觀節奏，將實際可使用樓層另列，絕不宣稱同時完整保留原圖所有細節。不能透過不真實的薄盒子或任意小數高度模擬 Minecraft 不存在的樓板。

## 骨架與窗的最小深度預算

以當層前立面外骨架為零深度：主直肋寬2格；玻璃退後2格；樓板伸至骨架面或再前出1格，總可見進深至少2格；白側緣返牆2–3格。前窗最寬可先取當地直徑的65–70%，背窗35–40%，再以正背渲染調整。

樓板用真半磚，主肋用完整方塊，保持柱比板厚；下方X用1–2格寬階梯狀肋線，交會處去除重複堆厚。玻璃用藍色主調，可少量淺藍形成分格，但避免青綠大面積或密集灰水平紋。室內樓板邊不要與外窗重合，避免深度失效或透明排序造成整面百葉窗效果。

## 園景與暖光點位

優先順序是輪廓、骨架深度、入口／附樓比例，再補暖光與園景。100格版本可縮減小花數，不能省掉全部暖光與立體灌木。

| 區域 | 建議放置 | 避免事項 |
| --- | --- | --- |
| 前樓板 | 每層左右最外端各1個螢石／暖燈；窄頂層合併 | 不做整條發光樓板 |
| 背窗 | 每隔1–2層在中央肋兩側各1個；退至窗後或板內側 | 不把中直肋全換螢石 |
| 入口 | 門左右1格寬光柱，頂部小燈 | 保持門扇與上下半部合法，不堵通道 |
| 圓亭簷口 | 4–6個等距燈，白柱與燈交錯 | 不讓燈吃掉全部窄窗 |
| 屋頂花園 | 每亭2–3叢灌木、1小樹、4燈；中裙樓6–8叢 | 樹葉不橫封入口與主要窗面 |
| 地面花壇 | 花壇分段，轉角與階梯側設燈，兩側留步道 | 不做全圓密集等距燈牆 |

螢石在本機展示可看出暖色，但無法靠模型檢視證明遊戲內光影、著色器光暈或夜景會與原圖相同。實際材質ID與狀態仍交由現有版本化registry核對。

## 本機驗收建議與未確認項目

1. 從實際canonical資料計算完整bounds，確認最低／最高格與總高≤100；包括燈、樹及所有階梯。重新計算材料與佔格，不按縮放比例推算舊數字。
2. 固定相機拍正、背、側、俯視圖；原圖與模型等顯示建築高度並排，只裁空白邊界，不拉伸、不分別挪動部件。所有截圖由同一份模型取得。
3. 檢查雙尖凹口、前窗左右白返牆、灰肋／半磚厚度差、背窗下尖與斜疊縫、附樓簷口及入口暖光；再檢查地面與屋頂園景。
4. 截面檢查玻璃退距及階梯動線，統計實際可站立可到達樓層。沒有此證據時只報26道外觀樓層帶。
5. 本輪不得使用任何Higgsfield生成、更新或其他可能耗點操作；既有214格展示即使可開啟也不是100格成果證據。僅本機資料／渲染／瀏覽器檢查仍不等於Minecraft遊戲內驗收。

100格高度是可行的近似重建尺度，但原圖細密的窗格、26道節奏、粗細多級白邊、豐富暖光與小型園景無法全部等比例無損保留。報告與介面應明確保留這個限制，不宣稱零差異。

## Round 3 獨立人工視檢

本節直接檢視 `evidence/golden-leaf-100-round3/golden-leaf-front.png`、`golden-leaf-rear.png`、`golden-leaf-top.png`，並對照本報告所列原始前後參考圖。這是可見外觀的判斷，不以測試通過推定與原圖一致；本次沒有重新計算高度，也沒有執行遊戲或通行測試。

### 核心已達成的可見項目

- 全塔、雙尖、兩側附樓及基座完整入鏡。高低雙葉、前寬窗與後窄窗不再混成同一立面；下部金殼有斜向交接。
- 前方主直肋與下部X變細後，不再大面積遮住窗；薄樓板、後退藍玻璃與白側緣有可見深度差。X仍可辨識，不是僅以平面紋理表現。
- 背窗縮短後保留較多下段金殼，中央直肋與成對暖燈可辨識；背縫走向保留，沒有橫腰帶。
- 前入口為藍色門廳及兩側暖光；背面偏右入口及階梯已可見。兩附樓的白柱、藍窗、厚簷與屋頂樹叢成立。
- 原先孤立盆栽已改成連片且略有高低的種植床。屋頂、地面、入口、附樓簷下與主塔樓板端部均看得到暖色光源點；俯視圖可辨識花壇分段與步道空隙。

### 尚未完全相符

1. **高尖白緣局部仍可改善：** 背面高尖留下較長純金內側段，白色內緣起點另有一小段水平突唇；原圖白邊較連續地貼向尖端。可考慮以1格白邊向上銜接、最高2–3格保留金尖，避免添出白十字或粗白帽。這是局部候選，不需要改整片葉殼。
2. **殼面與低尖仍較硬：** 整數格網造成較明顯的長階梯、低葉尖平截感與側面分段反光。原圖曲面更細密；在100格限制下不宜為抹平外形引入不能施工的小數盒體。
3. **層數與骨架不是精確複製：** 實作採23層的節奏，少於原圖目測約24–26道。細化後的X及直肋比例較好，但粗細、弧度與每層位置仍不同；上文26道方案只是設計比較，不代表本輪採用。
4. **窗面與燈光尚不同：** 現圖玻璃較暗、室內明暗變化較少，原圖明亮青藍反射與暖光較豐富。背窗數個左側燈在截圖中呈窄線、右側呈整方塊；可能與樓板遮擋或視角有關，應核對相應canonical格，不能單憑圖片判定螢石遺失。主要光源區域沒有整區缺漏。
5. **園景已補足但仍簡化：** 現有連片樹葉較像規整綠籬，原圖為大小不一的灌木、小樹、花與白花壇交錯；現圖附樓柱窗、入口與地面鋪面亦較粗。這些差異不能只以燈光解釋。

獨立判斷：**核心結構可作為100格版保留，尚未完全還原原圖。** 除高尖白緣及背燈局部資料確認外，不建議再全面重寫；保留明確差異比為追求圖片相似而破壞可施工格網更可靠。模型高度、材料數、通行與持久化是否通過，以主流程實際測量報告為準；本節不替代那些驗收。
