# 金葉塔：100 格重建與驗收

日期：2026-10-21。這份報告取代舊 214 格版本作為目前金葉塔的模型證據。高度、資料和網頁流程通過；視覺為參考重建，**未達零差異驗收**。

## 問題與參考分解

舊版全棟高度 214 格，不符合使用者新指定的 100 格上限。直接壓縮舊模型會讓門、半磚、樓梯與室內淨高失效，因此以新的整數格網重新設計。原圖已是 Minecraft 建築風格，差異不能只歸因於「需要方塊化」。

先直接重讀前後原圖，分解為七組：不等高雙金葉；厚白返邊；窗前灰色直肋及下段 X；內退藍玻璃與薄樓板；背面窄葉窗與斜向金殼重疊；雙圓亭／裙樓／前後入口；分層花園及各區暖光。完整分析和獨立視檢見 [參考解構](GOLDEN_LEAF_100_REFERENCE_AUDIT.md)。光暈不證明原作確切方塊 ID；螢石是本模型的可施工選材。

## 四輪本機改進

1. 重設 100 格外形、圓形截面、雙尖與前後不同開口。第一輪對照發現灰架過厚、花園零碎、後入口和窗內暖光缺漏。
2. 灰架調成單格、拉長下段 X、補後入口、連續花床、外殼曲線及可行樓梯。靜態通行檢查找出階梯被連通廊清除、平台頂部碰撞及附樓玻璃擋路，逐項修正。
3. 補 23 個前窗後螢石、錯落高低灌木、附樓及裙樓屋頂燈。把最後燈具置於植栽之後，防止覆寫。最大半徑微調，去掉孤立外凸格。
4. 獨立視檢後延續背面高尖白邊至 Y96，Y97–99 保留金色；收掉頂部白橫突。背窗 26 個燈移至樓板外緣，確認每個燈的外側相鄰格為空。

渲染只調整原創材質紋理、透明度、實際光源方塊的發光外觀和適合單棟尺度的陰影；沒有使用原圖貼面冒充模型。鐵門顏色亦修正為金屬色。材料、拾取、施工、下載仍使用同一份 canonical XYZ。

## 視覺對照與仍未通過的部分

直接觀看第四輪正面、背面、俯視及桌面／手機截圖。前後視角 yaw180°／0°、pitch14°；14° 是推估，未聲稱精準重建原相機。比較圖 `evidence/golden-leaf-100-comparison.png` 只裁空白邊並等比例顯示，不拉伸或重畫建築。

- 100 格版仍有更粗的葉殼階梯、較方的雙尖與返邊；23 道層帶少於原圖約24–26道。
- 灰架與玻璃有真實進深，但灰架、窗面與樓板在本機光照下的對比、反射、暖光仍不同；前 X 的視覺突出程度不足原圖。
- 金殼整體曲線及園景較規整，細窗格、花叢密度及部分比例尚有差異。不可說所有螢石與原作逐格一一相符，原作沒有可核對的方塊資料。
- 尺寸、隱藏側面與內部配置均標記 `AI Estimated Area`。圖片不足以確定不可見部分，沒有據此生成「精確還原」分數。

因此本輪交付的是可操作、可保存、符合100格上限的完整近似重建，未宣布原圖零差異完成。沒有在 Minecraft 中實際放置／遊玩驗收。
