# 金葉塔 V14 葉片比例重製（2026-10-21）

V13 與參考仍有明顯差距。本輪以原圖前後立面重新比較上肩、短尖和左右金葉厚薄；Astra medium 修改模型，Astra low 獨立比圖，主代理整合與驗證。付費生成呼叫 0，未使用 Higgsfield 點數。

## 原因與修正

V13 上段收尖過慢、短尖偏外；前後窗面都置中，造成兩側金葉近乎等厚，與原圖不符。背面窄斜唇也缺少葉片交疊的面積。

- 收窄上肩，短尖從 X10/Y90 移到 X7/Y89；高尖仍 Y99。
- 前窗、側壁與灰架中段一同沿世界 X 移 -2 格，後窗與脊柱移 -1 格，端點漸回中線。灰架上段配合窄冠到 Y88；保留實體面連通。
- 背面改為寬幅、一格厚的交疊金葉，加 25 個真實平滑石英上半磚作斜邊。最後一輪將白邊嵌回金殼一格，消除側面突出的白齒。
- 基座、月牙花園及入口保留。26 層和兩側花園仍通過靜態站立面通行檢查。
- 收藏頁可「查看新版 V14」，選已有新版或追加一次；保留舊建築、備註與編輯。

曾測試旋轉視角，但樓板會傾斜且不符原圖，因此保留前 180°、後 0°、俯角 14°，直接修正模型。沒有用圖片覆蓋真模型、拉伸畫面或外加平滑殼。
